# OpenFN Workflows Directory

## What to Commit

✅ **COMMIT these files:**
- `*/project.yaml` - Workflow configuration
- `*/jobs/*.js` - Job definitions
- `*/README.md` - Workflow documentation
- Any custom configuration files

❌ **DO NOT COMMIT these auto-generated directories:**
- `*/.versions/` - Downloaded workflow versions from server
- `*/.snapshots/` - Automatic backup snapshots
- `*/extracted/` - Extracted workflow files
- `*/.current-state.json` - Current sync state
- `*/.deployed-state.json` - Deployment state
- `*/.last-deployed.json` - Last deployment info
- `*/.state-backups/` - State backup files

These directories are automatically created by the workflow sync system and should remain local to each developer's environment.

## Directory Structure

```
workflow-name/
├── project.yaml          ✅ Commit
├── jobs/                 ✅ Commit
│   ├── job1.js          ✅ Commit
│   └── job2.js          ✅ Commit
├── README.md            ✅ Commit
├── .versions/           ❌ Auto-generated (git ignored)
├── .snapshots/          ❌ Auto-generated (git ignored)
└── extracted/           ❌ Auto-generated (git ignored)
```
